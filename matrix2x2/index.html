🧭 2×2 トレーニング

1つのお題で、切り口の違う2×2を3つ。書いて、撮って、フィードバック。
連続 0 日通算 0 回

ルール

  • このお題で 切り口（軸）の違う2×2を3つ 書く
  • 各フレームに「タイトル／縦軸・横軸の両端／4象限のラベルと具体例」を書く
  • 書けたら「フィードバック」タブで写真を送る
行き詰まったら：軸の切り口ヒントを見る

    手書きの2×2を撮影して送る

    お題：（まだお題がありません）
    3つを1枚に収めても、1枚ずつ（最大4枚）でもOK。字が読み取れるよう、明るい場所でまっすぐ撮ると精度が上がります。

    Anthropic APIキー

    お題の生成と写真の読み取りに使います。キーはこの端末のブラウザ（localStorage）にだけ保存され、Anthropic以外には送信されません。
    キー未設定でも、内蔵のお題リストからお題を出せます（フィードバックにはキーが必要）。
